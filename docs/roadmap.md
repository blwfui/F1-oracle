## 技术栈

- **数据**: FastF1 API（练习/圈速/轮胎/天气）+ Jolpi/Ergast API（排位/积分修正）
- **存储**: SQLite WAL 模式，7 张表
- **仪表板**: Streamlit + Plotly，F1 红色主题，全中文
- **依赖**: fastf1, pandas, numpy, streamlit, plotly, requests, pyarrow
